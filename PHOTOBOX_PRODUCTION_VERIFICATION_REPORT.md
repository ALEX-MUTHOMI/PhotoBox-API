### UWSGI Dependency Grouping

Root cause:

Decision:

- Moved `uwsgi` from main Poetry dependencies to optional `[tool.poetry.group.deploy]`.
- Local dev/test/lint/security install excludes deploy-only dependencies.
- Existing `requirements.txt` remains unchanged, preserving the current Docker/Linux deployment baseline where `uwsgi` builds successfully.
