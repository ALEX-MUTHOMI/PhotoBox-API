## Operating model

PhotoBox is documented here as a disposable, cloud-native service. The docs site itself is static, self-hosted, and production-friendly:

- No third-party font CDN is required.
- Search runs locally through Pagefind.
- The site builds to static assets and can sit behind any CDN.
- Content is split into focused pages so engineers can deep-link the exact subsystem they are discussing.
